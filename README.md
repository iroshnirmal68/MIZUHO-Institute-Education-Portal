# MIZUHO Institute — Puzzle Piece Education Website

## Pages
- `index.html` — landing page
- `about.html` — institute overview and values
- `programs.html` — academic pathways
- `admissions.html` — admissions process and application form
- `student-portal.html` — demo student login/portal
- `contact.html` — contact form and details

## Technologies
Pure HTML5, CSS3 and vanilla JavaScript. No build tools or frameworks are required.

## Run
Open `index.html` directly in a browser, or upload the entire folder to GitHub Pages, Netlify, Vercel static hosting, or another static host.

## Customize
Edit `css/style.css` for the visual system and `js/main.js` for the shared navigation/footer and interactions. Replace the demo contact details and forms with your real backend/API before production use.
